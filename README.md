# D2 Visual Editor

Двусторонний редактор диаграмм «код [D2](https://d2lang.com) ↔ визуальная схема». Правите код — схема обновляется; тащите блоки на схеме — код переписывается. Позиции элементов не теряются ни при переименовании, ни при переносе строк.

Открывается как обычный файл (`file://`), без сборки и сервера: весь UI в одном `index.html`, логика графа — в чистых ES5-модулях `js/*.js`.

## Возможности

- **Двусторонняя синхронизация**: правка кода (debounce 3 c) → parse → merge → схема; изменения схемы (drag, блоки, стрелки, группировка, rename) → перегенерация кода.
- **Позиции не теряются**: аннотированный D2 хранит координаты в маркере `# @d2pos x,y`; маркер в тексте авторитетен над эвристиками merge.
- **Схема на [@xyflow/system](https://xyflow.com)** (CDN): pan/zoom, drag блоков, dblclick-rename через модальный диалог, авто-расстановка новых блоков, «Упорядочить по связям».
- **Файлы**: импорт и экспорт D2 (нативный диалог сохранения, принудительное расширение `.d2`, запоминание имени файла), экспорт в самодостаточный SVG (можно открыть в браузере/Inkscape/на печать).
- **Хранение**: автосохранение в `localStorage`, миграция старого формата v1 → v2.

## Быстрый старт

```bash
# открыть приложение (нужен интернет для @xyflow/system с CDN)
xdg-open index.html
```

Пример кода для вставки (панель «Код D2» → меню «Копировать» → «Заменить»):

```
User -> Server -> Database
"Клиент" -> "Бэкенд" { label: "запрос" }
```

## Тесты

```bash
npm test          # 136 юнит-тестов (node:test), без внешних зависимостей
npm run test:ui   # 15 E2E-сценариев (puppeteer-core; нужен системный Chrome)
```

## Структура

```
index.html            весь UI (без сборки): панели «Код D2» и «Схема»,
                      меню импорта/экспорта, экспорт в SVG
js/d2-serialize.js    граф → D2-текст (чистый и аннотированный)    [window.d2mod]
js/d2-parse.js        D2-текст → граф (токенизатор + parseD2)      [window.d2parse]
js/d2-merge.js        слияние распарсенного графа с текущим         [window.d2merge]
js/d2-layout.js       авто-расстановка новых нод                    [window.d2layout]
js/d2-sort.js         упорядочение блоков по стрелкам               [window.d2sort]
test/*.test.mjs       юнит-тесты (node:test) + E2E (puppeteer-core)
docs/                 архитектура, разработка, план, README
```

Подробнее об архитектуре, merge-эвристиках и ограничениях — в `docs/` и `AGENTS.md`.
