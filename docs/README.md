# D2 visual editor — документация

Двусторонний редактор диаграмм: слева код [D2](https://d2lang.com), справа интерактивная схема. Любая правка кода применяется к схеме (после debounce ~3 c), а изменения схемы — обратно в код. Позиции элементов не теряются ни при переименовании, ни при переносе строк.

## Быстрый старт

```bash
# открыть приложение (без сборки и без интернета; @xyflow/system — локальный vendor)
xdg-open index.html

# юнит-тесты (188): node:test, без внешних зависимостей
npm test

# E2E (20 сценариев) — нужен системный Chrome
CHROME=/usr/bin/google-chrome-stable npm run test:ui
```

```

                      (Вставить/Заменить/Импорт…/Экспорт…/Экспорт в SVG; Draw.io и Mermaid — стабы);
```

## Ключевые идеи

1. **Граф — источник истины** для хранения и структуры; D2-текст — проекция графа (см. `docs/architecture.md`).
2. **`order`** — единственный порядок эмиссии текста (id нод и рёбер вперемешку).
3. **Маркер `# @d2pos x,y`** — зарезервированный формат, хранит позицию в тексте. Переключается кнопкой «Скрыть/Показать позиции».
4. **Правка текста** (debounce 3 c) → parse → merge (перенос позиций) → render; правки схемы (drag и т.п.) → перегенерация текста, только если он «чист».
5. **Экспорт/импорт**: файлы D2 (нативный диалог сохранения, принудительное `.d2`, имя запоминается в `d2editor:ui:v1`), импорт из `.d2`/`.txt`, SVG-экспорт (самодостаточный векторный документ из графа); Draw.io и Mermaid — в плане (стабы в меню).
6. **Приоритеты разработки**: в первую очередь — полноценная поддержка D2 (справочники `docs/plans/d2-*-coverage.md` — опора для разработки, статусы ✅/⚠️/❌); во вторую — собственные удобства, строго не противоречащие D2. Подробнее — §0 `AGENTS.md`.
