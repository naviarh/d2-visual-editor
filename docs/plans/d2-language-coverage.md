# D2: перечень возможностей языка и статус реализации

Сверено с авторитетными источниками:
- Официальная грамматика и ключевые слова: `d2ast/keywords.go` в `https://github.com/d2lang/d2` (master), парсер `d2parser/parse.go`.
- Доки языка: `https://github.com/d2lang/d2-docs` (`docs/tour/*.md`: `strings`, `comments`, `connections`, `containers`, `vars`, `classes`, `globs`, `imports`, `overrides`, `positions`, `text`, `composition`).
- CLI `d2 v0.7.1` (проверки `d2 validate`, `d2 fmt`, компиляция в SVG) — прямое сверение поведения.

Статусы:
- ✅ — реализовано в проекте (паритет с d2);
- ⚠️ — распознаётся и сохраняется без потерь, но семантика (валидация значений, применение) не воспроизводится;
- ❌ — не реализовано: либо явная ошибка «не поддерживается», либо молча неверная трактовка (например, ключ превращается в обычную ноду/метку), либо сознательное ограничение проекта.

Модули проекта: `js/d2-parse.js` (парсер), `js/d2-serialize.js` (сериализаторы), `js/d2-merge.js`, UI — `index.html`.

Смежный документ: `docs/plans/d2-visualization-coverage.md` — возможности *визуализации* D2 (формы, стили, темы, экспорт) со статусами реализации. Этот файл охватывает *синтаксис и семантику языка*.

## 1. Лексика: пробелы, отступы, разделители

| Возможность | Статус | Комментарий |
|---|---|---|
| Отступы не значимы; структура — только через `{}` | ✅ | Парсер без чувствительности к отступам |
| `;` — терминатор/разделитель стейтментов (`a; b; c: { d; e }`) | ✅ | `;` — терминатор в токенизаторе |
| Несколько атрибутов на одной строке | ✅ | |
| Пробелы в unquoted-строках не разделители (`a b c` — один ключ) | ✅ | Паритет с d2 |
| Пустая строка — только визуальный разделитель, семантики не несёт | ✅ | |
| `{` `}` — открытие/закрытие скоупов | ✅ | |
| `[` `]` — массивы значений | ✅ | |
| `(` `)` — только синтаксис ссылки на ребро `(a -> b)[0]` | ❌ | Ошибка «неожиданный текст после оператора» |

## 2. Комментарии

| Возможность | Статус | Комментарий |
|---|---|---|
| Строчные `#` (от `#` до конца строки) | ✅ | Паритет с d2 `parseComment` |
| Инлайн-`#` после оператора прикрепляется к своему элементу | ✅ | Сохраняется при round-trip: `x -> y # note` |
| Соседние `#`-строки сохраняются; в d2 склеиваются в один комментарий | ✅ | Проект хранит строки раздельно, контент не теряется |
| Блочные `"""…"""` (могут быть многострочными) | ✅ | Round-trip: хранятся как `{text, block:true}` и эмитятся снова как `"""` (однострочные — `""" x """`, пустой — `"""  """`, как `d2 fmt`); контент деиндентится при парсинге и пере-индентится при эмиссии |
| `#` внутри quoted-строки не комментарий | ✅ | `x: "#notacomment"` → метка |
| `#` внутри unquoted-значения начинает комментарий | ✅ | `x: a#b` → метка `a`, комментарий `# b` (паритет с d2 fmt) |
| `//` НЕ комментарий (часть unquoted-строки) | ✅ | Сознательный паритет: `Client // note` — ключ |
| Блочный комментарий между объектами | ✅ | |
| Маркер `# --- @d2pos x,y` в конце строки (расширение проекта) | ✅ | Служебный; `POS_RE` (якорь конца строки); legacy-форма `# @d2pos x,y` тоже разбирается |

| Трим ведущих/хвостовых пробелов unquoted | ✅ | |
| Single-quoted `'…'` | ✅ | |
| Double-quoted `"…"` | ✅ | |
| Escape-набор D2 в `"…"` (`\b \t \n \v \f \r \" \\ \$` и т.д.) | ✅ | `d2Escape`/`decodeEscape`; неизвестные escapes теряют `\` (паритет) |
| Многострочные double-quoted | ❌ | Ошибка (в d2 тоже ошибка — паритет) |

## 7. Зарезервированные ключевые слова

Список слева — из `d2ast/keywords.go` (авторитетная грамматика d2). В d2 ключевые слова «резервированы» только в контексте атрибута внутри скоупа; на верхнем уровне (корень диаграммы) они — обычные объекты (паритет с проектом, проверено `d2 fmt`: `shape: rectangle` → объект `shape`).

### 7.1 Простые ключевые слова

| Ключ | Статус проекта | Комментарий |
|---|---|---|
| `label` | ✅ | Поле `label` |
| `shape` | ✅ | Поле `shape` (регистр сохраняется) |
| `icon` | ⚠️ | `rawAttrs`; не рендерится |
| `tooltip` | ⚠️ | `rawAttrs`; не рендерится |
| `link` | ⚠️ | `rawAttrs`; не рендерится |
| `near` | ⚠️ | `rawAttrs`; d2 валидирует значение (8 констант или абсолютный id — иначе ошибка компиляции), проект не валидирует |
| `width` / `height` | ⚠️ | `rawAttrs`; d2 требует целочисленное значение (иначе ошибка), проект не валидирует и не применяет |
| `direction` | ⚠️ | В скоупе — `rawAttrs`; на верхнем уровне — нода. d2 валидирует `up/down/right/left` |
| `top` / `left` | ❌ | Не `RESERVED` → вложенные ноды; в d2 — жёсткая фиксация (TALA) |
| `grid-rows` / `grid-columns` | ❌ | Не `RESERVED` → вложенные ноды |
| `grid-gap` | ⚠️ | `rawAttrs`; не применяется |
| `vertical-gap` / `horizontal-gap` | ❌ | Не `RESERVED` → вложенные ноды |
| `class` | ❌ | Не `RESERVED` → вложенная нода |
| `constraint` | ❌ | Не `RESERVED` → вложенная нода; в d2 — группировка для композиции |
| `vars` | ❌ | Обычный контейнер |

### 7.2 Ключевые слова-«держатели» (составные значения)

| Ключ | Статус проекта | Комментарий |
|---|---|---|
| `style` | ⚠️ | `rawAttrs` (произвольное дерево сохраняется lossless); d2 требует быть `style: { … }`, иначе «reserved keyword style must be composite» |
| `source-arrowhead` / `target-arrowhead` | ⚠️ | Сохраняются lossless в теле ребра; рендер — только дефолтный треугольник |
| `classes` | ❌ | Обычный контейнер |
| `layers` / `scenarios` / `steps` | ❌ | Обычные контейнеры (см. §17) |
| `label`/`icon`/`tooltip` как composite (`label: { near: … }`) | ⚠️ | Сохраняется lossless как карта; значение/`near` не применяются |

### 7.3 Style-ключевые слова (в d2 — только внутри `style:`)

| Ключ | Статус проекта | Комментарий |
|---|---|---|
| `opacity`, `stroke`, `fill`, `stroke-width`, `border-radius`, `font-size`, `shadow` | ⚠️ | В проекте `RESERVED` на верхнем уровне скоупа → `rawAttrs`. В d2 вне `style` это ошибка компиляции («fill must be style.fill»). Внутри `style:` в проекте тоже lossless |
| `fill-pattern`, `stroke-dash`, `font`, `font-color`, `bold`, `italic`, `underline`, `text-transform`, `multiple`, `double-border`, `3d`, `animated`, `filled` | ⚠️ | Не в `RESERVED` проекта, но внутри `style:` сохраняются lossless как содержимое карты `style`; на верхнем уровне скоупа — вложенные ноды |

**Дополнительно:** проект добавляет собственные зарезервированные ключи, которых нет в d2: `dir` (направление стрелки), `gap`, `pad`, `pad-x`, `pad-y`, `text-font-size`.

| Globs-соединения (`* -> *`) | ❌ | Ошибка «globs (*) не поддерживаются» |
| Ребро к необъявленной ноде | ✅ | Неявная нода |

## 15. Overrides и null

## 18. Грамматические тонкости и расхождения

| Возможность | Статус | Комментарий |

| Запятая — не разделитель в D2 | ✅ | Паритет |
| Ключи консервативно (unquoted `[A-Za-z0-9_]+` или `"…"`); d2 fmt не трогает кавычки | ✅ | `d2Key` |

| Детекция `$`/`*`/`...@` на сырых символах до decodeEscape | ✅ | |

| **Неизвестное имя shape** | ⚠️ | d2: `d2 validate` ок, компиляция падает «unknown shape»; проект: сохраняет и рисует fallback-прямоугольник |
| **Невалидные значения зарезервированных ключей** (`near: foo`, `direction: foo`, `width: foo`, `grid-rows: foo`) | ⚠️ | d2: ошибка компиляции; проект: lossless без валидации |
| **`label.foo: bar`** | ⚠️ | d2: ошибка компиляции «unexpected field foo»; проект: вложенная карта `label → foo` |

## 21. Итог

**Полный паритет:** лексика (пробелы/`;`/`{}`), строки (unquoted/single/double/блоки с произвольными кавычками), комментарии (`#`, inline, склейка), точечные пути и quoted-сегменты, объекты и значения, все 4 формы соединений с цепочками/циклами/повторами/картами-атрибутов, контейнеры и подписи, массивы, неявные ноды, ошибки с номерами строк.

**Паритет, но без применения/валидации значений (lossless в `rawAttrs`):** `style`-дерево, `near`, `width/height`, `icon`, `tooltip`, `link`, `direction`, `grid-gap`, `label/icon/tooltip`-composite, arrowheads, top-level style-ключи (в d2 вне `style:` — ошибка).

**Не реализовано (ошибка или молча неверно):** `vars` и подстановки `${}`, `classes`/`class`, globs (`* ** *** & !&`), импорты (`@`, `...@`, partial/relative/absolute), `layers/scenarios/steps`, `constraint`, `top`/`left`/`grid-rows`/`grid-columns`/`vertical-gap`/`horizontal-gap`/`class`/`vars` как резервные ключи, `null`-overrides, ссылки на рёбра `(a->b)[N]`, `_`-ссылка на родителя, лимит длины ключа, autoformat отступов блок-строк.

**Кандидаты на реализацию «в первую очередь»** (приоритеты и порядок работ — §0 `AGENTS.md`; реализация идёт через чистые функции в `js/*` + юнит-тесты по §8 `AGENTS.md`): `null`-значения (удаление из графа — естественно ложится на merge-слой), ссылки на рёбра `(a->b)[N]`, резервные ключи `top/left/grid-rows/grid-columns/class/vars/constraint` (признание их «зарезервированными» вместо вложенных нод), валидация значений зарезервированных ключей по образцу d2, лимит длины ключа 518.
