# D2: перечень возможностей визуализации и статус реализации

Сверено с официальными источниками:
- Тур D2: `https://d2lang.com/tour/` (страницы: `shapes`, `connections`, `strings`, `text`, `icons`, `dimensions`, `positions`, `style`, `themes`, `fonts`, `layouts`, `containers`, `composition`, `imports`, `vars`, `classes`, `globs`, `overrides`, `sql-tables`, `uml-classes`, `sequence-diagrams`, `grid-diagrams`, `legend`, `interactive`, `sketch`, `exports`, `man`).
- Исходники доков: `https://github.com/d2lang/d2-docs` (`docs/tour/*.md`).
- Репозиторий CLI: `https://github.com/d2lang/d2`, CLI `d2 v0.7.1` (сверка паритета форм/конструкций проводилась напрямую).

Статусы:
- ✅ — реализовано в проекте;
- ⚠️ — распознаётся и сохраняется без потерь (как правило в `rawAttrs`/поле модели), но не влияет на рендер/поведение;
- ❌ — не реализовано (явная ошибка парсера «не поддерживается» либо молча не применяется).

Структура файла повторяет порядок тура. Ссылки на модули — `js/*.js`, UI — `index.html`.

Смежный документ: `docs/plans/d2-language-coverage.md` — *синтаксис и семантика языка* D2 (лексика, строки, ключи, зарезервированные слова, соединения, подстановки, классы, globs, импорты) со статусами реализации. Этот файл охватывает возможности *визуализации*.

## 1. Объекты, ключи, подписи

| Возможность | Статус | Комментарий |
|---|---|---|
| Объявление ноды одним словом (`x`) | ✅ | Парсер/сериализатор (`d2-parse.js`, `d2-serialize.js`) |
| Несколько объектов на строке через `;` (`SQLite; Cassandra`) | ✅ | `;` — терминатор стейтмента в токенизаторе |
| Своя подпись через `pg: PostgreSQL` | ✅ | Поле `label`, эмиссия `label:` |
| Ключевое слово `label` в теле блока (`x: { label: … }`) | ✅ | `parseAttrBody` → `label` |
| Unquoted-строки: пробелы не разделители, хвостовые пробелы тримятся | ✅ | §4 AGENTS.md, паритет с d2 CLI |
| Quoted-строки `'…'` и `"…"` с экранированием | ✅ | `d2Escape`, паритет escape-набора |
| `# --- @d2pos x,y` — служебный маркер позиции (расширение проекта, не D2) | ✅ | `POS_RE` (принимает и legacy `# @d2pos x,y`); в D2 нет |
| Объявление внутри скоупа как атрибут (`x: { a: b }`) | ✅ | Вложенные ноды |

## 2. Соединения

| Возможность | Статус | Комментарий |
|---|---|---|
| 4 формы: `--`, `->`, `<-`, `<->` | ✅ | Поле `dir` (хранится при `!== "->"`), рендер маркеров по концам |
| `-*`/`*-` нормализуются в `->` | ✅ | Паритет с d2 |
| Подпись соединения (`a -> b: label`) | ✅ | `label` ребра, рендер `.elabel` |
| Повторные соединения — новые связи (не перезапись) | ✅ | Каждая запись — отдельное ребро |
| Цепочки `a -> b -> c` | ✅ | `parseEdge` поддерживает цепочки |
| Циклы (`x -> x`, `a -> b -> a`) | ✅ | Рендер самопетель/циклов |
| Ребро к необъявленной ноде создаёт неявную ноду | ✅ | `implicit: true`, merge по id |
| Наконечники `source-arrowhead` / `target-arrowhead` (shape, label у наконечника) | ❌ | В `RESERVED` → `rawAttrs`, рендер — только дефолтный треугольник |
| Ссылки на соединения по индексу (`(a -> b)[0].…`) | ⚠️ | Парсится и сворачивается при парсинге: `.label` → поле ребра (рендерится), прочие атрибуты (`style.*` и т.п.) → `rawAttrs` (не визуализируются — как и весь `style`, статус ⚠️). Ссылка без индекса создаёт новое параллельное ребро (паритет d2) |

## 4. Строки, блоки, текст

| Возможность | Статус | Комментарий |
|---|---|---|
| Блочные строки `\|tag` / `\|\|` / `` \|` `` / `\|-` (произвольные кавычки) | ✅ | §4 AGENTS.md; парсинг + эмиссия без потерь |

## 5. Формы (shapes)

| Возможность | Статус | Комментарий |
|---|---|---|
| Каталог из 18 форм: `rectangle, square, page, parallelogram, document, cylinder, queue, package, step, callout, stored_data, person, diamond, oval, circle, hexagon, cloud, c4-person` | ✅ | `SHAPE_NAMES` в `d2-shapes.js`; сверено с каталогом тура и CLI (18/18) |
| Регистронезависимость имён форм | ✅ | `getShape` → lowercase |
| Неизвестное имя формы валидно (fallback-прямоугольник) | ✅ | Паритет `d2 validate` |
| 1:1 ratio (`circle`, `square`) — нормализация по максимуму w/h | ✅ | `normalizeRatio` |
| `shape` на ребре / массивы / блок-строки — lossless в `rawAttrs` | ✅ | d2 их игнорирует в рендере |
| **`shape: sql_table`** (ER-диаграммы, колонки/типы/констрейнты PK/FK/UNQ) | ❌ | Fallback-прямоугольник; строки становятся вложенными нодами |
| **`shape: class`** (UML-классы, поля/методы, видимость `+ - #`) | ❌ | Fallback-прямоугольник |
| **`shape: sequence_diagram`** (акторы, спаны, группы, заметки, self-messages, lifeline) | ❌ | Fallback-прямоугольник; общий scope акторов не моделируется |
| **`shape: image`** (встраивание картинки) | ❌ | Fallback; `icon` — в `rawAttrs` |
| `shape: text` | ❌ | Fallback-прямоугольник |

## Итог

**Полностью реализовано:** базовые объекты и подписи, все 4 формы соединений, цепочки/циклы/повторные связи, контейнеры с подписями, полный каталог из 18 форм с анкоровкой рёбер, блочные строки без потерь, строки/escape-паритет, экспорт SVG и D2, собственные расширения редактора.

**Распознаётся, но не визуализируется (`rawAttrs`, lossless):** `style`-дерево, `near`, `width/height`, `icon`, `tooltip`, `link`, `direction`, `arrowhead`-настройки, root-стили.

**Не реализовано (сознательно или отсутствует):** специальные формы (`sql_table`, `class`, `sequence_diagram`, `image`, `text`), grid-диаграммы, легенда, темы, кастомные шрифты, layout-движки, композиция досок, классы/globs/импорты/подстановки, sketch-mode, интерактив (tooltip/link), экспорт PNG/PDF/PPTX/GIF/ASCII/Draw.io/Mermaid, `_`-ссылки, null-overrides.

Потенциально «следующими» кандидатами на реализацию выглядят: рендер Markdown в блочных метках, `near` (константы) как привязка к сторонам, `style.fill/stroke/stroke-width/font-size` для нод и рёбер, `width/height`, `icon`, `tooltip`/`link` (кликабельность в SVG-экспорте) и направленность `direction`. Реализация любой из них должна идти через чистые функции в `js/*` с юнит-тестами (§8 AGENTS.md).
